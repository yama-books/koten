# マスコット画像

© 2026 koten contributors / CC BY 4.0

`assets/icons/app-icon-hyakunin-1254.png`（アプリアイコン）の右下に描かれたネコを切り出したものです。
アイコンと同じ絵なので、ホーム画面のアイコンと画面内のネコが同一のものだと分かります。

| ファイル | 用途 |
|---|---|
| `cat-mascot.png` | 編集用の原本（512px） |
| `cat-mascot.webp` | 公開画面で使用（256px・品質84） |

## 使用条件

- **装飾である。** 情報を持たせない。`alt=""` と `aria-hidden` を付け、読み上げから外す。
  ネコに意味を持たせると、画像が出ない環境でその意味が失われる。
- 背景は透過。切り抜きは**色の一致ではなく、外周からの塗りつぶし**で行う。
  ネコの体色は背景色にごく近いので、色で判定すると体まで消える。輪郭線が閉じている
  ことを利用して、画像の縁から届く範囲だけを透明にする。
- 背景を生成り色で焼き込まないこと。地色（`--color-paper`）とわずかにずれ、
  拡大すると四角い縁が見える。
- 縦横比を維持する。
- アイコンを差し替えたときは、この素材も同じ元画像から切り出し直す。
