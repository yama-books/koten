# 回答フィードバック画像

© 2026 koten contributors / CC BY 4.0

初回公開版で使用する手書き風フィードバック素材です。いずれも依頼者提供画像を参考に、輪郭を滑らかに整えた透過PNGです。

| ファイル | 用途 |
|---|---|
| `correct-maru.png` | 1問ごとの正解 |
| `needs-review-check.png` | 不正解または自己評価「×」。「要確認！」の文言と併用 |
| `perfect-hanamaru.png` | 全問正解時の結果画面 |

公開画面では、上の元PNGから最大512px・品質84で生成した同名の `.webp` 3点を使用する。元PNGは編集用として保持する。

## 使用条件

- 色だけで正誤を伝えず、文言または読み上げ用テキストを併用する。
- アニメーションは約0.3秒の控えめな表示にし、`prefers-reduced-motion` では停止する。
- 画像の縦横比を維持する。
- 公開実装時に見た目を比較確認しながら、PNG最適化またはWebP/AVIF派生版を生成してよい。元PNGは保持する。
- 権利表示は、公開前のライセンス確認結果に従う。
