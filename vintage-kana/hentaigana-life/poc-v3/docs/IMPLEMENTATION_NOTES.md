# PoC v3 実装ノート

## なぜファイルを分けるか

PoC v2までは単一HTMLが高速な試作に向いていた。
v3以降は、長時間状態・ログ・背景改変・句読点・育成・工房へ拡張するため、単一HTMLでは変更範囲と責務が混ざる。

本PoCはビルドツールを要求しない。GitHub Pagesにそのまま配置できる。

## 責務分離

- `index.html`: DOM骨格のみ
- `assets/css/app.css`: 見た目
- `js/data/*`: キャラクター・世界・行動・句読点の宣言データ
- `js/core/*`: 状態・保存・ログ・実行ループ
- `js/sim/*`: 行動選択・環境改変・句読点解釈
- `js/ui/*`: DOM描画
- `schema/*`: 永続化データの契約
- `docs/*`: 実装判断

## なぜES Modulesではなく古典scriptか

初期PoCでは、ユーザーがHTMLをダブルクリックして `file://` から開けることを優先する。
JSON `fetch()` や module import はローカル直開きで制約が出やすいため、ランタイム設定は `HKLife` 名前空間へ読み込む `.js` とした。

本番化時にVite等へ移行する場合も、責務分離はそのまま移せる。

## 保存

IndexedDBを主、localStorageをフォールバックとする。

- WORLD_SNAPSHOT: IndexedDB
- 再開時: savedAtとの差で論理時間補間
- 30秒ごと＋一定tickごとに保存
