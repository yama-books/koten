# PoC v3 固定した実装判断

1. 代表8体を継続使用する。
2. 性格パラメータは内部に存在するがUIへ表示しない。
3. UIで確定表示する文字情報は「読み」「字母」。
4. 行動は候補の重み付き選択。
5. `idle` を高めに置き、事件密度を抑える。
6. 穴掘りを最初の永続的背景改変とする。
7. `。` と `、` を最初の可塑的記号とする。
8. 同じ記号に対し、個体ごとに異なる `interpretation` を持てる。
9. 観察ログと内部ログを分離する。
10. IndexedDBへ世界状態を保存する。
11. 再開時は簡易論理時間を進める。
12. 背景はレイヤー構造で描画する。
13. 時間帯は世界時計から自動判定する。
14. 変体仮名Webフォントは外部読込のまま。フォントバイナリはこのパッケージへ含めない。
15. GitHubへの反映は、この段階では行わない。
