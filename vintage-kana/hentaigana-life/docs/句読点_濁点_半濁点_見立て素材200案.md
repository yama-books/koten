# 句読点・濁点・半濁点「見立て素材」200案

## 基本方針

句点・読点・濁点・半濁点は、固定された意味を持つアイテムではなく、**形を持つ可塑的な素材／小生物**として扱う。

重要なのは「これは卵」「これはボール」と最初から決めることではなく、**置かれた環境・他の記号との組み合わせ・各個体の扱い方によって、何に見えるかが後から決まる**ことである。

同じ `。` でも、

- 蹴られる → ボール
- 巣で温められる → 卵
- 土に埋められる → 種
- 水中へ入る → 泡
- 夜空へ上がる → 星・月

となり得る。

さらに、文字ごとに同じ物への解釈が違ってよい。

- 喜は `。` をボールと思う
- 母は卵と思う
- 農は種と思う
- 寶は大切な物と思う

この**解釈の食い違いそのものを即興劇にする**。

## 基本変換文法

- `、 + 、 ⇄ ゛`
- `。 ⇄ ゜`
- `。。 ⇄ ゛`（縮小・膨張などの条件を介する）
- `。 + 、` → 果実、尾のある生物、道具など
- `゜ + 、` → 虫眼鏡、網、鍵、クラゲなど
- `゜ + ゜` → 鎖・輪の連結
- `。` 多数 → 泡、石垣、星座、実の房
- `、` 多数 → 草、雨、煙、鎖、風

## 実装時の重要ルール

### 「正体」ではなく「現在の見立て」を持つ

句読点トークン自体には、卵・ボール・泡という固定クラスを与えない。代わりに、

- glyph
- size
- weight
- elasticity
- buoyancy
- wetness
- temperature
- stickiness
- linked_to
- holder
- area
- history

などの物理・履歴属性を持たせる。

そこから、その瞬間に可能な `affordance` を算出する。

### 個体ごとに解釈が異なる

一つの句点に対して複数個体が同時に別の解釈を持てる。

例：

1. 喜が句点を蹴る → 「ボール」
2. 母がそれを拾う → 「卵」
3. 農が土へ埋める → 「種」
4. 翌日、春Ⅰが芽を見つける

句点自身は同じIDのまま、**扱われた履歴だけが積み重なる**。

### 変形は可逆でよい

`、+、` が濁点になっても、永久に濁点へ固定しない。
水流・事故・遊びで再び二つの読点へ分かれてよい。

### 記録すべきなのは「何になったか」だけではない

観察ログには、

- 誰が
- 何を
- 何に見立てて
- どう扱ったか
- 他の個体がそれをどう解釈したか

を保存する。

この記録を蓄積すると、「物への見立て方」も個体の性格として発見できる。
