# 変体仮名を飼う / Hentaigana Life

変体仮名を「個体」として観察し、少人数の箱庭の中で自律的に生活させる実験アプリです。

## 現在の位置づけ
- 既存の変体仮名アプリ本体とは分離して試作を進めます。
- PoC v2以降は、固定イベント再生から「長時間自律生活・観察ログ・背景改変・句読点の見立て」へ軸を移しています。
- 性格値はユーザーへ直接表示せず、読みと字母を確定情報として、行動履歴から個性を発見する設計です。

## ディレクトリ
- `docs/`: 統合設計書、句読点・濁点・半濁点の見立て案
- `poc-v3/`: 分割構成によるPoC v3
- 既存の単一HTML PoC v1/v2は親ディレクトリ `vintage-kana/` に残します。

PoC v3は、まず長時間自動運転ログを取り、
「個体差が読めるか」「何もしない時間が成立するか」「句読点の解釈差が自然に出るか」「生活の痕跡が背景へ残るか」
を検証するための基盤です。
