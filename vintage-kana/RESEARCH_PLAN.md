# RESEARCH_PLAN — vintage-kana

最終更新: 2026-09-18

## 目的

変体仮名の実際の使用を資料に即して観察し、

- 字体クイズ
- 字母クイズ
- 実資料読解
- 現代文を変体仮名で書く際の根拠付き候補提示

へ利用できる実例コーパスを作る。

## 原則

### 万能規則を先に作らない
作品・時代・ジャンル・版・書写資料を混ぜた全体頻度から、「この仮名にはこの字体が正しい」と決めない。

### 同一資料内の観察を先に行う
資料単位で、
- どの字体が何例あるか
- 語頭 / 語中 / 語尾
- 文節位置
- 助詞
- 前後文字
- 連綿
を観察する。

### 比較はその後
複数資料を比較して初めて、
- 資料固有
- 作品群に共通
- 時代的傾向の可能性
を区別する。

## フェーズ

### Phase 0: 書誌台帳
work_id, title, witness_id, witness_name, volume, date, period, genre, medium, holding_institution, source_url, license, notes を保存。

### Phase 1: 字体分布
47仮名について資料ごとに、
- 対応する仮名
- 字母
- 字形ID
- 出現数
- 総出現数に対する比率
を収集。ここでは理由を推測しない。

### Phase 2: 実文脈採取
高頻度字体と特徴的字体について、各字体5〜20例程度を目安に採取。

### Phase 3: 条件別集計
十分な件数が集まった資料のみ、
- 語
- 語頭 / 語中 / 語尾
- 文節位置
- 助詞
- 前後文字
- 連綿
別に集計。

### Phase 4: 研究文献との照合
観察した傾向を先行研究と比較する。

### Phase 5: 教材候補化
- 一字問題: 国語研字体マスターのみで作成可能
- 語・短句問題: `attested` のみ自動候補化
- 長文問題: 原資料画像と翻刻の両方を人間が確認後に公開

## NG

- AI生成文を「江戸時代の自然な変体仮名文」として出す
- 資料横断頻度だけで字体を自動選択
- 研究対象の異なる論文結果を無条件に統合
- 原資料へ遡れない用例を attested とする
- CODHの現代仮名Unicodeラベルだけから字母・変体仮名字体を断定
