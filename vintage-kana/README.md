# vintage-kana

変体仮名を、歴史的な書記文化としての性質をできるだけ損なわずに学び、読み、現代的な遊びとして書いてみるための教材・Webアプリ企画。

最終更新: 2026-09-18

- **[DESIGN_HISTORY.md](DESIGN_HISTORY.md)** — 最初の「暗号文」構想から現在の資料重視方針までの詳細な設計史。撤廃案と、その撤廃理由も記録。

## 中心原則

本プロジェクトでは、変体仮名を「任意の記号に置き換える暗号表」として扱わない。

過去の試作では、変体仮名を本来対応しない仮名へ割り当てる換字暗号や、候補字体を無作為に選ぶ「ゆらぎ暗号」を検討したが、歴史的な書記体系を歪める可能性があるため撤廃する。

字体選択には、資料・時代・書き手・語・語内位置・文節位置・助詞・前後文字・連綿などが関係する可能性がある。したがって「同じ仮名に対応する字体なら、どれでも無作為に置き換えてよい」とは扱わない。

ただし、最初の構想にあった「知らない人には読みづらい」「読めるようになると秘密の手紙を解くようで楽しい」という体験は捨てない。文字体系を改変する暗号ではなく、**歴史的な変体仮名そのものを読めるようになる楽しさ**として残す。

## 学習機能の三本柱

### 1. 字体・字母を学ぶ

国立国語研究所「学術情報交換用変体仮名」を基礎資料とし、

- 変体仮名 → 対応する仮名
- 変体仮名 → 字母
- 字母 → 変体仮名
- 同じ仮名に対応する複数字体の比較

を行う。

利用者向け表示は原則として、

- 対応する仮名
- 字母
- 必要な場合のみ備考

とする。

「本来の平仮名」「本来の読み」「暗号上の割り当て」という表現は使わない。
Unicode番号は内部識別に保持してよいが、通常UIには表示しない。

### 2. 実資料を読む

読解教材は、原則として実在資料から採取した用例を用いる。

学習段階の例:

1. 一字
2. 実資料中の短い語
3. 実資料中の短句
4. 数行程度
5. 原資料画像そのもの

各問題から典拠へ遡れるようにする。

### 3. 変体仮名で書いてみる

現代の文章を変体仮名で表記して遊ぶ機能は残せるが、「歴史的な字体選択を再現したもの」とは扱わない。

当面は自動ランダム変換ではなく、

1. 現代仮名を入力
2. 対応する変体仮名候補を表示
3. 字母・実例・資料別傾向を確認
4. 利用者自身が字体を選択

という方式を優先する。

## 実例と創作の区別

教材データには必ず `provenance_type` を持たせる。

- `attested`: 実資料に確認できる用例
- `adapted`: 実資料を教材上の都合で最小限加工
- `constructed`: 教材用に作成した例
- `modern_composition`: 現代文を変体仮名で表記したもの

読解教材の既定は `attested` とする。
