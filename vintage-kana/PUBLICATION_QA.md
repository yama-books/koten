## RC2 / 濁音・小書き仮名

実ブラウザ確認で「書いてみる」に以下の問題を確認。

- 清音「て」は字体候補へ変換できる
- 濁音「で」は候補対象にならない
- 拗音の小書き「ょ」などが字体候補として扱われない

原因:
- UIが `GLYPHS[].kana` と入力文字を完全一致で比較しており、清音1文字だけを対象にしていた。

修正:
- 濁音・半濁音を基本清音＋結合濁点／半濁点へ分解
- 例: `で → て + U+3099`
- 小書き仮名を基本仮名へ対応付け
- 例: `ょ → よ`
- 小書き字体候補はCSSで縮小表示
- 「小書き表示は現代的な補助表現であり、歴史的な小書き慣習の再現ではない」とUIに明記
- 原文保持を初期値とし、利用者選択式は維持

対象:
- 濁音: が〜ご、ざ〜ぞ、だ〜ど、ば〜ぼ、ゔ
- 半濁音: ぱ〜ぽ
- 小書き: ぁぃぅぇぉゃゅょっゎ

検査:
- JavaScript構文: PASS
- `で → て + 濁点` mapping: PASS
- `ょ → よ + small` mapping: PASS
- strict publication gate: 維持

## RC16 / 拗音は歴史寄りの大書きを初期値

拗音表示の初期値を変更。

背景:
- 歴史的仮名遣い対照表では、現代の「きょう」に対して「きよう」「きやう」「けう」「けふ」等を示す
- 現代的な小書きは、歴史資料そのものの再現とは別の表示上の慣習
- 「小書き＝歴史的に本来の形」とは扱わない

UI:
- 初期状態では ゃ・ゅ・ょ を通常サイズ表示
- 「自分で選ぶ」時のみ「ゃ・ゅ・ょを小さく表示」チェックを表示
- チェック初期値は OFF
- チェック時のみ現代的な小書き表示
- おまかせへ戻すと OFF に戻す

注意:
- これは歴史的仮名遣いへの語彙変換ではない
- 例: 「今日」は単純な「きよう」ではなく歴史的仮名遣いでは「けふ」
- 本機能は字形・サイズ表示の設定

検査:
- JavaScript構文 PASS
- default OFF PASS
- auto mode full-size PASS
