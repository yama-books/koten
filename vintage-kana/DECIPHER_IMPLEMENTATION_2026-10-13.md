## 1. ユーザー確定仕様

- 習得のクイズメニュー順は **読み / 字母 / 解読**。
- 解読は語・短文・ことわざ・流行語・作品関連等の第一次確定 **371語句・10カテゴリ**を出題する。
- 除外 `なんとかなる` / `だめよだめだめ` / `むげんのかなたへ` / `ひとのゆめはおわらねえ` / `むだむだむだ`。復活 `きみのなは` / `となりのととろ`。追加 `あきらめたらしあいおわり`（元の作品の直接引用ではない創作表現）。
- 同じ仮名を含む語でも、**位置ごとに独立して字体をランダム抽選**。固定の字体パターン集は持たず、候補は字形マスターの正しい読み/字母対応に限定する。
- ５段階のレベル、仮名出現履歴による語句抽選重み、最近出た問題の抑制、読みの文字列入力。
- 文脈から正解を推測しても正解とし、**画面に実際に表示した各字形へ正解記録・加点**。同一出題の同字形は一回だけ、誤答時は各字形の誤答を断定しない。
- 現代仮名遣いの創作教材であり、歴史資料の実際の組み合わせではないことをUIに明示する。
- 実在古典の歴史的仮名遣いによる読解教材は VK-06 と区分する。

## 2. 実装とデータ

- `data/decipher-phrases.json` : 371件、安定ID `dc-0001`〜`dc-0371`、正解ひらがな、カテゴリ、教材由来を共通メタデータで定義。小書き仮名・長音符を含まない。
- `decipher-engine.js` : データ検証、仮名の清音基底への対応、５段階の字母候補、出題履歴に基づく語句重み、字形ごとの習熟度を踏まえた出題時のランダム抽選、回答正規化、字形別イベント展開、レベル昇降。
- `detail.html` : 解読タブ、選択可能な難易度、文字列解答、正誤・字母表示、５問セット結果、記録画面へ解読の件数を追加。
- `mastery-summary.js` と `index.html` : シンプル版と詳しい版の共通習熟度に解読成功の字形イベントを読み込み、旧一字問題のイベントを保持する。
- `tests/unit/vintage-kana-decipher.test.ts` : データ・生成・正解加点・レベル昇降・UI導線の回帰確認。

保存:
- 旧１字問題記録 `vintage-kana:learning-events:v1` **不変**。
- 解読履歴 `vintage-kana:decipher-history:v1` を別キーに保存し、成功字形イベントは**集計時に導出**（二重書込なし）。
- 解読レベル `vintage-kana:decipher-level:v1`。
- 語句の採点単位は１問、正解時の字形習熟は別単位。

## 3. 難易度／自動昇降

| レベル | 文字数 | 変体仮名候補 |
|---|---|---|
| 1 | 2〜3 | 頻度順最上位1字母1字形 |
| 2 | 3〜4 | 同上 |
| 3 | 4〜6 | 字母を最大2種類 |
| 4 | 5〜8 | 字母を最大3種類 |
| 5 | 7〜20 | 登録された全字形 |

基点の `totalObserved` は収集済み15資料の観測であり、**歴史的一般頻度ではない**。候補の初期順序以外の歴史的正当性を主張しない。

直近10問中８問正解、異なる語句6・異なる字形7以上を昇級条件とする。直近8問で4問以上不正解ならレベルを一つ下げる。利用者はレベルを直接選択可能。記録の原本は消さない。
