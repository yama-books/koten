# 変体仮名メーカー　生命感・閃光・刻印演出 改善設計
作成日: 2026-10-01
対象: `vintage-kana/prototypes/cinematic-motion-v1/`
基準: MOTION STUDY 29

## 1. 目的
文字を単なる図形として動かすのではなく、「様子を見る」「ためらう」「先導する」「失敗する」「気づく」「慌てて直す」といった因果のある動きを持たせ、文字が小動物や人間のように命を持っている印象を作る。

重点:
- 非トルネード系の閃光入りを自然にする
- サイズ変化を演出パターンとして追加する
- かくれんぼを「ちら見→先導→追従」の寸劇にする
- はぐれ者を単なる軌道差ではなく短いコメディとして設計する
- 最終刻印にも「遅刻・ひっくり返り・順番違い・位置ずれ」などの失敗と復帰を入れる
- 改行、逆変換、レスポンシブ移動範囲、白化単調増加を壊さない

## 2. 閃光入り
`文字が存在する → 閃光が始まる → 文字が白く発光・にじむ → 光に溶けて消える`

- 非トルネード系では閃光直前まで opacity を高く維持
- 中心収縮を早く始めすぎない
- 閃光開始と同時に brightness / blur を上げる
- opacity 低下は閃光ピークに同期
- 白化は単調増加、完全白静止なし
- 白の中で次フェーズ運動を開始

## 3. サイズ変化
`scaleMode` を再生開始時に一度だけ抽選:
- `steady`
- `breath`: 0.88〜1.14倍、文字ごとに位相差
- `pulse`: 0.78〜1.24倍、縮む→戻る→膨らむ

## 4. 命があるように見える条件
ためらい、様子見、他個体への反応、反応の時間差、失敗、気づき、修正、追従を重視する。

## 5. かくれんぼ
状態:
`hidden → peek1 → retreat → peek2 → watch → leader-walk → followers-walk → gather`

- ちらっ
- 一度引っ込む
- ちらちら
- 一文字が先にトコトコ
- 他の文字は端から見る
- 安全そうだと判断したように時間差で追従

## 6. はぐれ者
- `sticky`: 剥がれ遅れ→震える→ぺろん→急追
- `reverse`: 逆走→停止→方向転換→急追
- `drop`: ポロリ→バタつく→急上昇
- `overshoot`: 行き過ぎ→停止→戻る→微調整
- `wrongspot`: 間違った場所に整列→気づく→移動
- `late-chaser`: 本隊が遠ざかってから急追
- `camera-slap`: ビターン→焦る→剥がれる→追う

## 7. 最終刻印
基本:
- `bouncy`: 現行のかわいい刻印
- `heavy`: 落下→ドン→一瞬つぶれる→小さく戻る→ピタッ

## 8. 最終刻印コミカル異常
`stampGag`:
- `none`
- `late`: 一文字だけ遅刻
- `flip`: 逆さ/横倒しで着地→クルッと修正
- `swap`: 2文字が位置を取り違え→あとで入れ替わる
- `offset`: 少しずれて着地→周囲を見て正位置へ
- `overshoot`: 行き過ぎ→戻って微調整

共通原則:
`失敗 → 間 → 気づき → 慌てる/修正 → 正位置`

確率案:
- 70% none
- 18% 軽い異常
- 9% 明確な異常
- 3% 強い異常

## 12. 2026-10-01 追加設計: 白い世界を全前半の共通チェックポイントにする
どの前半パターンでも、必ず以下の順序を通る。

```text
通常空間
→ 白背景世界へ侵入
→ 白背景世界の中でその前半固有の運動を継続
→ 一定時間滞在
→ 閃光
→ 閃光後
```

要件:
- 白背景への到達はトルネード固有ではなく全前半の共通仕様
- 白背景が十分に白くなる前に閃光を開始しない
- 白背景到達後も最低 0.8〜1.2 秒程度、固有運動を継続して見せる
- 縦上下では高速化が始まる頃から白背景への侵入を開始し、真っ白な空間の中で「ドドドドド」を十分に見せてから閃光
- 白化は単調増加で、途中で元の背景へ戻らない
- 白背景の中でも文字の運動を止めない

## 13. 大小脈動の「ゴゴゴゴ」前半
`scaleMode=pulse` を単なる補助倍率ではなく、独立した見せ場として強化する。

```text
小さな脈動
→ 振幅増大
→ 白背景へ侵入
→ 真っ白な世界の中で激しい大小脈動 + 微振動
→ ゴゴゴゴゴ
→ 閃光
```

- 文字ごとの位相差は維持
- 同期感のある回と波が伝播する回の両方を許容
- 最大時は通常より明確に大きく、最小時は縮こまる
- 閃光直前まで輪郭を保ち、閃光に同期して白く溶ける

## 14. 閃光後の語順崩壊
閃光後の灰・花びら・放射線・落下・かくれんぼでは、文字の視覚的な並び順を一度壊す。

候補:
- `shuffle`: 完全シャッフル
- `reverse`: 完全逆順
- `partial`: 数文字単位で入れ替え

特に「ひらがなに戻す」復号では、意味のある語順がすぐ見えない状態を強くする。

重要:
- DOM上の文字対応そのものは壊さない
- 閃光後の位置割り当てだけをシャッフルする
- 後半の再集合で正しい語順・正しい個体対応へ戻す

## 15. 後半の社会的なやり取り
後半に `socialMode` を追加し、文字同士の関係性を見せる。

候補:
- `none`
- `squabble`: 押す→押される→やり返す→どちらかが譲る
- `follow`: 一人が動き、周囲が遅れて追従

### squabble
- 2文字をペアに選ぶ
- A が B の領域へ押し込む
- B が一度押される
- B が押し返す
- A が少し引く
- 最後は双方が本来の軌道へ戻る
- 接触の意味が視覚的に読めるよう、タイミングに「間」を入れる

## 16. 円環の「のんびりさん」「載りそびれさん」
せっかちな個体だけでなく、遅い個体を増やす。

候補:
- `slowpoke`: 明らかに低速で、群れが先へ行ってから「？」と気づき急追
- `miss-orbit`: 円環へ入るタイミングを逃し、外周であたふた。何度か入り口を探してから合流

視覚上の要件:
- 速度差は小差ではなく明確な差にする
- 「乗れなかった」「置いていかれた」が一目で分かる
- あたふた中は左右に迷い、短い停止、逆向きの一歩などを入れる
- 最後は正しい群れへ復帰する

## 17. 最終刻印: 割り込み挿入
新しい `stampGag=insert` を追加する。

例: 「あさきゆめみし」
1. 最初は「み」を抜いた状態で「あさきゆめし」が詰まって確定したように見える
2. 遅れて「み」が到着
3. 「め」と「し」の間へ入ろうとするが隙間がない
4. 一度押し返される / 小さく跳ね返る
5. 再度ぐいっと押し込む
6. 左右の文字が少しずつ譲る
7. 「み」が間に入る
8. 全体が正しい最終位置へ再整列

制約:
- 横一行の短〜中程度文字列を優先して発生
- 複数行・縦書きなど複雑な配置では既存の late/offset にフォールバックしてよい
- 最終結果は必ず正しい文字列

## 18. 人間的・動物的な描写の追加原則
単なるランダム差ではなく「役割」と「反応」を持たせる。

役割例:
- リーダー
- のんびり
- おとぼけ
- 臆病
- せっかち
- 押しが強い
- 負けず嫌い
- 追従者

生命感を出す最小単位は、
`刺激 → 間 → 判断したような反応 → 結果`
とする。

例:
- 他者が先に進む → 一拍見る → 自分も進む
- 押される → 一瞬止まる → 押し返す
- 置いていかれる → 周囲を見回す → 慌てて追う
- 間違った場所にいる → しばらく堂々としている → 気づく → 修正

## 19. 追加受入条件
- 全前半で白背景世界へ完全に到達し、そこで固有運動を一定時間見せてから閃光へ入る
- pulse 回では「ゴゴゴゴ」と分かる大振幅の大小脈動が白背景内で見える
- 閃光後は文字順が壊れ、特に復号時に元の語がすぐ読めない
- 後半に押し合い・やり返しが見える回がある
- slowpoke / miss-orbit が early より目立つ頻度で出る
- 円環へ載りそびれて外周であたふたする個体が視覚的に分かる
- 刻印 insert では「一度完成した列に遅刻文字が無理やり入り、周囲が譲る」寸劇が成立する


## 20. 追加設計: 「白背景に入ってからが本番」
白背景は閃光直前の短い予告ではなく、全前半モーションに共通する変身の主舞台とする。

共通進行:
```text
通常空間
→ 加速開始
→ 白背景・縦線が見え始める
→ 白背景へ完全侵入
→ 白背景内でさらに加速・激化
→ 白背景内で見せ場を一定時間維持
→ 圧縮・発光
→ 閃光
```

ルール:
- どの前半モードでも、加速が始まる頃から白背景への侵入を開始する
- 白背景が十分に白くなったあとも、すぐ閃光へ行かず、固有運動を最低1.2秒程度見せる
- 白背景内で「通常空間より一段強い」運動へ必ず移行する
- 縦線・ラッシュライン・微振動・発光も白背景突入後に強くする
- 文字は閃光開始まで見える状態を保ち、閃光と同期して白く溶ける
- 白化は単調増加で元へ戻らない

目標:
「白くなって終わる」ではなく、「白い精神と時の部屋へ入り、そこで本気の変身運動が始まる」と感じられること。

## 21. 新規前半: 左右・斜めの脱水モーション
上下系と同じく、同期型と独立型を持つ。

### `side-shake-sync`
- 全体が同じ大きな左右往復をする
- 加速とともに横幅が広がる
- 白背景内では左右端近くまで激しく振られる
- 往復端では横方向に押しつぶされる
- 回転と微細な上下振動を重ね、洗濯機の脱水のような圧を出す

### `side-shake-random`
- 各文字が自分専用の横ラインを持つ
- 周期・位相・振幅を文字ごとに固定乱数で変える
- 白背景内では互い違いに左右を高速往復し、ガタガタした脱水感を出す
- X運動が主で、Yは小さなバタつきに留める

### `diagonal-sync`
- 全体が同じ斜め軸上を往復
- 画面左下↔右上、または左上↔右下を大きく使う
- 白背景に入ると反射周期が短くなり、斜めの衝撃運動へ移る

### `diagonal-random`
- 各文字が異なる斜め軸・周期・位相を持つ
- 白背景内で斜めの往復・反射が密になり、画面全体を使う
- 完全ランダムウォークではなく、各文字の軸は再生中固定する

共通:
- 画面サイズではなく安全表示領域の割合で最大振幅を決める
- スマホでは画面外へ消えず、PCでは中央に縮こまらない
- 白背景侵入後に振幅・速度・潰れ・回転をさらに増す

## 22. 円環・竜系の「乗り遅れ」を寸劇化
`miss-orbit` は微妙なずれではなく、誰が見ても「乗り遅れた」と分かる大げさな失敗として描く。

### 円環・circle/ring時
1. 本隊が円環へ入り回転開始
2. 1文字だけ円環のかなり外側に残る
3. 入ろうとして入口へ向かう
4. 円環が進んでしまい1回目失敗
5. 逆方向へ少し戻って再挑戦
6. また入口を外して2回目失敗
7. 一瞬ぽつーんと停止
8. 左右へ小刻みに向きを変え「あれ？」という間
9. その場であわあわ足踏み
10. 急加速して外周から合流
11. 合流直前に少し行き過ぎ、微調整して収まる

### dragon時
1. 本隊が竜の流れになって画面を大きく移動
2. 1文字だけ元の近辺にぽつーんと残る
3. 本隊が遠ざかってから初めて気づく
4. 左右を見回す / 小さく震える
5. 少し逆方向へ走ってしまう
6. 慌てて反転
7. 本隊の1.8〜2.4倍程度の見かけ速度で追跡
8. 尾の後方へ飛び乗る

視覚要件:
- 本隊と取り残された文字の距離差を大きくする
- 「静止の間」を必ず入れ、認知の遅れを見せる
- あわあわは小刻みなX/Y振動と回転で表す
- 本隊は待たない
- 最後は必ず復帰する

## 23. のんびり・おとぼけの頻度
せっかちな `early` より、遅い・忘れる・乗りそびれる個体を目立たせる。

推奨重み:
- slowpoke: 35%
- miss-orbit: 35%
- reverse: 8%
- drop: 8%
- overshoot: 6%
- wander: 5%
- early: 3%

「差が小さい」ではなく、明らかに速度や反応時間が違うことを優先する。

## 24. 追加受入条件
- 竜巻以外でも白背景への侵入が早く、白背景内の見せ場が短く終わらない
- 全前半モードで「白背景に入ってからさらに激しくなる」ことが分かる
- 左右同期 / 左右独立 / 斜め同期 / 斜め独立がランダムおよびデバッグで確認できる
- 左右系は洗濯機・脱水のように押しつぶされながら高速往復する
- miss-orbit は本隊から明確に取り残され、最低1回以上の合流失敗と「あれ？」の間が見える
- dragon + miss-orbit では、一文字がぽつーんと残り、本隊が遠ざかってから慌てて追う
- slowpoke / miss-orbit の出現頻度が early より明確に高い
