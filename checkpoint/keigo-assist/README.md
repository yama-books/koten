# 敬語訳アシスト v0.4（試作）

古文予習ノート（Checkpoint）の学習思想に沿って、古文敬語をどう読むかを**生徒が自分で考えるための独立試作**です。本文の敬語候補を示し、地の文／会話文、話し手、動作主、相手、受益者、尊敬・謙譲・丁寧などの用法仮説から、敬意の方向を組み立てます。

## 起動

`index.html` をブラウザで開いてください。Node.js・外部API・ログインは不要です（オフライン動作）。公開版Checkpointへの接続やリンク追加は**まだ行っていません**。

## 機能

- 敬語候補15語をもとに本文中の候補をハイライト。辞書にない語は選択範囲から手動追加。
- 対象語ごとに尊敬／謙譲／丁寧／特殊な謙譲／非敬語の候補を選択・保留。
- 誰の動作か、動作の相手／行き先、受益者、地の文／会話文／引用／手紙、話し手／聞き手を記入。
- 敬意を示す側から対象への関係を**学習者の仮説**として図示し、次の検討観点を表示。
- 自分の現代語訳を書き、入力内容をJSONで書き出せる（自動保存なし）。

## 正確性と公開上の注意

- **学習支援用PoCであり、教材としての正解データではありません。** 敬語用法・語義は `reviewStatus: proposed` 相当で、人手による文法・用例・典拠監査を終えていません。
- 例文は試験用の構成文で、古典作品から確認した用例ではありません。
- 語の部分一致は確定解析ではありません。下二段「給ふ」のような特殊な謙譲は通常の謙譲矢印に単純化しません。
- 入力本文・人物情報・訳はサーバーへ送信せず、ブラウザ内で扱います。エクスポートするJSONには入力情報が含まれます。
- 予習ノート本体（`checkpoint/index.html` など）や学習履歴・既存検出処理は変更していません。

## 次工程

- Checkpointの既存敬語データ `checkpoint/data/inflecting_words.json` との重複・差異を監査する。
- 人物関係と用法を **語の出現位置ごと** に紐づける連携アダプタの受入仕様を整理する。
- 典拠付き代表用例の収集と、人の承認を経てから学習者向け正解表示を検討する。
- 公開本体の変更や production `main` への取り込みは、別途統合工程で判断する。
