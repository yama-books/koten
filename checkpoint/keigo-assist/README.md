# 敬語訳アシスト v0.5（質問型UI）

古文予習ノートから本文を引き継ぎ、敬語についての質問に順に答えると、人物関係と訳し方のヒントがまとまる試作です。

## 画面

1. 本文から敬語を選ぶ（候補を押す／選択範囲を手動追加）
2. 質問に一つずつ答える（文章の場面、動作主、用法。必要に応じて相手・聞き手）
3. 回答結果として場面・動作主・用法・敬意の対象と、短い訳のヒントを示す

最初にすべての説明を並べず、選択・回答した情報だけを表示します。画面上の注記・長い説明・詳細パネル・JSON書き出し・自由作文欄は削除しました。

## 連携

- 単体ページ：`/koten/checkpoint/keigo-assist/`
- 古文予習ノート：`/koten/checkpoint/` の「敬語の訳し方」または敬語詳細の「この敬語の訳を考える」
- 本文（最大10,000文字）と選択範囲のUTF-16位置を同一オリジンの `postMessage` で受け取る。
- 本文・回答はURLや外部サーバーへ送らず、画面を閉じると引き継いだ本文は予習ノート側に残る。アシスト側は自動保存をしない。

## 内部の位置付け

- v0.4の敬語候補15語、複数用法候補、敬意の主体・対象を区別するロジックを維持している。
- 語形の部分一致は文法的な確定ではない。画面では「用法を決めない」「分からない」を選べるようにして、結果を正答判定として扱わない。
- 原典の典拠・用例監査は未完了。教材としての正解データを追加する際には、別工程で検証する。
- Checkpoint本体の連携スクリプトや公開ワークフロー、他の古典アプリには変更を加えない。
