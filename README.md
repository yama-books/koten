# 古典学習帳（仮称）

中学生・高校生が、小倉百人一首の本文・読み・作者を自分の試験範囲に合わせて反復確認するためのWebアプリです。成績処理や学校アカウントとの連携は行いません。

「古典学習帳」は設計・実装中の仮称です。正式名称は公開準備時に確定します。

## 現在の状態

設計・基礎データ整備段階です。アプリ本体は未実装です。確定仕様は [`docs/APP_SPEC.md`](docs/APP_SPEC.md)、実装順序は [`docs/OPUS_IMPLEMENTATION_PLAN.md`](docs/OPUS_IMPLEMENTATION_PLAN.md) を参照してください。

## 初回公開で目指すこと

- `?from=10&to=20` のようなURLで学習範囲を指定できる
- 「とりあえず始める」から、穴埋めと作者確認へすぐ入れる
- 見るだけ、おぼえる、全体確認、試験前の確認を使い分けられる
- 本文と問題は縦書き、操作と進捗は横書きで表示する
- 習熟度を％・メーター・5色で示し、次に確認する内容を提案する
- 学習履歴を端末内に保存し、JSONまたは文字列で別端末へ統合できる
- 学年別の匿名利用統計を、指導上の参考として管理者が確認できる

## 初回公開に含めないもの

- 成績・学校システムとの連携
- 必須ログインとクラウド同期
- QRコードによる端末共有
- かるた練習・対戦
- 助動詞・文法問題、現代語訳などの詳しい解説
- 生成AIによる公開時の問題生成

助動詞・文法は初回公開後の最優先追加です。クラウド同期、かるた練習、対戦、現代語訳の順に段階導入します。

## データの扱い

本文・作者・読みのMarkdownを正本とし、生成JSONは派生物として作り直せる状態にします。正本の本文を変換処理や問題生成から書き換えません。句切れ、穴埋め候補、作者別名、助動詞注釈は別データとして人が確認します。

主な基礎資料：

- `百人一首_本文・作者_一次データ.md`
- `百人一首_読み_歴史的仮名遣い.md`
- `百人一首_読み_現代仮名遣い.md`
- `百人一首_読み_異同確認.md`
- `古典文法_一次データ索引.md`

## 公開構成

公開用リポジトリと、内部運用資料・管理ツールを置く非公開リポジトリを分離します。公開版は静的Webアプリを基本とし、GitHub Pages等で配信します。Firebaseは匿名統計、問題報告、将来の任意同期に限定して使用します。
