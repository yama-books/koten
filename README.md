# 百人一首練習帳（テスト公開版）

中学生・高校生が、小倉百人一首の本文・読み・作者を、自分の試験範囲に合わせて反復確認するための Web アプリです。**ログインは不要で、学習の記録は端末の中だけに保存されます。** 成績処理や学校アカウントとの連携は行いません。

**「古典学習帳」は開発中の仮称です。** 正式名称は未確定で、公開名義は暫定的に `koten contributors` としています。

## これはテスト公開版です

**正式公開ではありません。** 動作を確かめていただくための版で、下の「まだできないこと」を読んでから使ってください。

- 版: **0.1.0**
- 匿名統計の送信は**行いません**（機能が未実装のため、送信経路そのものが無効です）
- 学習の記録は**この端末の中だけ**にあります。書き出さずに閲覧データを消すと失われます

## いまできること

- `?from=10&to=20` のような URL で学習範囲を指定できる
- 6 つの入口を使い分けられる —— **とりあえず始める / 歌を確認する / 作者名を確認する / 歌本文（穴埋めで確認） / 作者（歌と作者を結びつける） / 本番（試験のように解いて採点）**
- **穴埋め 500 問**（100 首 × 5 句。**句を丸ごと隠す形だけ**です）と**作者 300 問**（1 首につき選択式・読み・記述の 3 形式）
- 歴史的仮名遣いを正解、現代仮名遣いを部分正解として区別する
- 本文と問題は縦書き、操作と進捗は横書き。縦横は切り替えられる
- 読みを「ルビなし / 歴史的仮名遣い / 現代仮名遣い」で切り替えられる
- 習熟度を ％・メーター・5 色で示し、次に確認する内容を提案する
- 学習履歴を端末内に保存し、JSON または文字列で別の端末へ移して統合できる
- 気づいた誤りをその場で報告できる（**報告は端末内に保存されます。送信はしません**）

## まだできないこと（隠さずに書きます）

- **匿名の利用統計は送信しません。** 送信の仕組みが未実装です
- **報告した内容は送信されません。** 端末内に残るだけです
- **穴埋めは「句」単位だけです。** 語単位・文節単位の穴埋めは作っていません
- **読みの異同がある 10 首は、人の校正が済んでいません。** 該当の歌には画面上に注記が出ます
- **縦書きの改行位置は、まだ人が校正していません。** 狭い画面で不自然に折り返す歌があります
- **作者の別名・有職読みの正答範囲は、まだ人が校正していません。** 正しい別の呼び方が不正解になることがあります
- **iOS Safari / Android Chrome / iPad Safari を並べた実機記録は、まだ取っていません。** 手元の環境では動きますが、機種ごとの網羅確認は済んでいません
- 助動詞・文法問題、現代語訳などの解説はありません
- クラウド同期、かるた練習、対戦はありません

助動詞・文法を最優先で追加し、そのあとクラウド同期、かるた練習、対戦、現代語訳の順に検討します。

## データの扱い

本文・作者・読みの Markdown を**正本**とし、生成 JSON は**派生物**として作り直せる状態にしています。**正本の本文を、変換処理や問題生成から書き換えることはありません。** 句切れ、穴埋め候補、作者別名は別データとして人が確認します。

主な基礎資料:

- `百人一首_本文・作者_一次データ.md`
- `百人一首_読み_歴史的仮名遣い.md`
- `百人一首_読み_現代仮名遣い.md`
- `百人一首_読み_異同確認.md`

人の確認結果は `review/*.yaml` に記録しています。**確認者は個人名ではなく役割表記（`human-01` など）で書きます。**

## 開発

```bash
npm ci
npm run data:build   # 正本の Markdown から JSON を生成する
npm test             # Node 試験と画面試験
npm run build        # 公開用ビルド
```

`npm run data:check` は、生成物が正本と食い違っていないかを検査します（書き換えは行いません）。
