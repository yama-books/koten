# ロールバック手順（内部資料。公開しない）

計画 P12 の項目 9。**配信物・データ・統計の 3 つは戻し方が違う。** 順に書く。

**前提**: 公開リポジトリは新規アカウントの空リポジトリに `git init` から作った新しい履歴である。
非公開リポジトリ `koten` とは **remote を共有していない**。片方を戻しても、もう片方は動かない。

---

## 1. まず止める（数分で効く順）

| 症状 | 最初にやること |
|---|---|
| 配信物が壊れている（画面が出ない・出題が出ない） | **Pages を無効化する。** リポジトリの Settings → Pages → Source を None にする。URL は 404 になるが、壊れた版を配り続けるよりよい |
| 公開してはいけないものが混入した | **リポジトリを private に戻す。** Settings → General → Danger Zone → Change visibility。**ただし §4 を読むこと——一度公開したものは消えない** |
| Firebase の課金が動き出した | `packages/shared/src/app-config.ts` の **`firebaseEnabled` を `false`** にして再デプロイする。**学習機能は影響を受けない**（送信待ちが端末の outbox に溜まるだけ） |

---

## 2. 1 つ前のビルドへ戻す

**Pages は成果物ではなく `main` から作り直される。** したがって戻し方は「コードを戻して作り直す」である。

```bash
# 公開リポジトリで
git log --oneline -10          # 戻したい commit を選ぶ
git revert <戻したい commit>    # 履歴を消さずに打ち消す（推奨）
git push
```

`Deploy Pages` ワークフローが `main` への push で走り、作り直して配信する。
**`git reset --hard` と force push は使わない。** 公開履歴を書き換えると、
既に clone した人の手元と食い違い、何が配られていたのかが追えなくなる。

**ワークフローが途中で落ちた場合**、`data:check` と `scan:publish` のどちらで落ちたかを見る。
**どちらも「配信を止めるための門」なので、門を外して通してはならない。** 原因を直す。

---

## 3. データを戻す

**利用者の学習履歴は `dataVersion` に依存しない。** したがって生成データを戻しても履歴は失われない。

```bash
# 非公開リポジトリで、正本の Markdown を戻してから
npm run data:build
npm run data:check     # 終了コード 0 を確認する
```

**台帳（`review/*.yaml`）の承認を取り消す場合**は `tools/review-approve` の `set` に
`--status pending` を渡す。**承認を消すと `questions.*.json` が空になり、
「見るだけ」以外の入口が閉じる**（`packages/hyakunin/src/domain/entry.ts` の `isEntryAvailable`）。
**これは 2026-09-04 まで実際にそうなっていた状態である。** 意図せず戻さないこと。

---

## 4. 戻せないもの（先に知っておくこと）

- **公開した URL は検索インデックスとキャッシュに残る。** private に戻しても、
  第三者のキャッシュ・アーカイブからは消えない。
- **公開リポジトリの履歴に一度入ったファイルは消えない。** `git filter-repo` で書き換えても、
  fork とキャッシュには残る。**だから移管は新規履歴で行い、`scan:publish` を門にしている。**
- **Firestore のロケーション `asia-northeast1` は変更できない**（H-05）。
- **利用者の端末に保存された履歴は、こちらから消せない。** 初期化は利用者の操作である。

## 5. 判断の目安

**戻すべき**——公開物に秘密情報・内部資料・許可未確認の原資料が入った（停止条件 S-12）。
主要な実機で操作不能（S-6）。統計 payload が個人を特定しうる（S-9）。

**戻さなくてよい**——既知の制約が「まだできないこと」として README に書いてあるもの。
**それは欠陥ではなく、隠していないことがこの版の約束である**（憲章 §10 項目 8）。
