### 5.1 破壊試験（**受入の中心。「実装しました。全部緑です」は受け付けない**）

**足した試験が証明力を持つことを、意図的に論理を 1 箇所だけ反転させて示すこと。**
**ファイルごと消す壊し方は認めない**（変換段階で落ちて因果が証明できないため）。
**壊したら必ず元へ戻し、戻した後の `sha256sum` を報告に含める。**

| # | 反転させる論理（1箇所） | 赤くなるべき試験 |
|---|---|---|
| **B-1** | `H1` の変換を恒等にする | `H1` の適用試験が名指しで赤 |
| **B-2** | `H1-a`（語頭保護）を無効にする | `はな → はな` の**非適用**試験が赤 |
| **B-3** | `H1-c`（助詞保護）を無効にする | `花は → 花は` の非適用試験が赤 |
| **B-4** | `D1-a`（例外語保護）を無効にする | `つづく` `ちぢむ` `みかづき` `はなぢ` の保持試験が赤 |
| **B-5** | `W2-a`（助詞の を 保護）を無効にする | `本を → 本を` の非適用試験が赤 |
| **B-6** | **適用順を変える**（`H1` を `L1`〜`L3` の後に回す） | §7.2 の適用順を固定した試験が赤 |
| **B-7** | **小書きの整形（`S1`）を最初に回す** | 同上 |
| **B-8** | `appliedRules` から 1 件だけ落とす | `expectedRules` を固定した試験が赤 |
| **B-9** | `normalization.ts` の項目を 1 つ無効にする | §7.3 の該当試験が赤 |
| **B-10** | 引数のオブジェクトを 1 箇所だけ書き換える（破壊的にする） | A-6 の入力非破壊試験が赤 |

**どれかが赤くならなかった場合、「全部緑でした」と報告せず、赤くならなかった旨を報告して止まること。**
