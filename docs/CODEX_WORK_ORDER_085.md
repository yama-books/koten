# 発注085: 句未満の区切りを正本表記へ移し、台帳として書き出す

**これは発注書である。** 起草: 親担当（Claude Opus 5）・2026-09-15。
**想定担当: Sonnet（別セッション）。** 受入条件はすべて機械判定できる。

## 1. 何をするのか

**資料 `百人一首_句未満ランダム空欄候補_v3.md` の区切りを、アプリの正本表記の上へ移し、
`review/blank-chunks.yaml` として書き出す。**

資料は**許容表記**で書かれている（`[紅葉]/ふみ分け`）。アプリの正本表記は `もみぢふみわけ` である。
**両者は同じ句の別の書き方**で、読みを共有する。**その共有された読みを介して境目を運ぶ。**

```
資料   [紅葉] / ふみ分け      ← 許容表記の上の区切り
読み   もみぢ   ふみわけ      ← 共有されている
正本   もみぢ | ふみわけ      ← ここへ移す（成果物）
```

**この発注では問題を1問も作らない。** データを1つ作るだけである。使うのは別発注（工程3）。

## 4. 使ってよい既存の道具（**同じ探索をやり直さないこと**）

- **`tools/build-data/mixed-forms.ts`**
  - `chunks(text)` — 漢字のかたまりとかなに切り分ける
  - `alignments(text, reading)` — 漢字のかたまりへ読みを割り付ける（**後戻りあり**）。
    **貪欲一致では割り付けられない句がある**（`いく野の道の`・`ふるき軒端の`）。
  - `mixedForms(text, readings)` — 漢字とかなの全組み合わせ
- **`packages/hyakunin/src/data/generated/poems.json`** — `ku[5]`・`reading.historical.ku[5]`・
  `acceptedTextForms[5]`

**資料のかたまり列を読みへ割り付ける関数は新しく要る。** `alignments` は漢字のかたまり単位で、
資料のかたまりは送り仮名を含む（`来にけらし`）ので、そのままでは使えない。
**かなの位置は字どおり一致、漢字は 1 文字以上**という規則で数え上げればよい。

## 8. 受入条件（**すべて機械判定できる**）

1. `review/blank-chunks.yaml` の `entries` が **500 件**あり、`cardNo` 1〜100 × `ku` 1〜5 を
   **過不足なく覆う**。
2. **各句で `chunks` をつないだものが `poems.json` の正本表記と一致する。**
3. **各句で `readings` をつないだものが `reading.historical.ku` と一致する。**
4. **`chunks[i]` が全部かなのとき、`readings[i]` はそれと同じ文字列である。**
   **ただし踊り字を含むかたまりは除く**——`6番 第1句 かさゝぎの`（読み `かささぎの`）は
   表記と読みが**字として**食い違う。資料もここを `[かさゝぎ]/の` と割っているので、
   **この条件をそのまま課すと発注が達成不能になる**（2026-09-15・親担当が検算で発見）。
   踊り字（`ゝ ゞ ヽ ヾ 々`）を含むかたまりは、**読みが 1 文字ずつ対応していなくてよい。**
   対象はこの 1 句だけである（実測）。
5. **`chunks` と `readings` と `candidate` の長さが揃っている。**
6. **§2 の 11 句が、表のとおりの `readings` を持つ。**（11 句を名指しで確かめる）
7. **誤形が作れないこと**——2番第2句の `chunks`/`readings` から `mixedForms` を作ったとき、
   `夏つきにけらし` と `な来にけらし` が**含まれない**。同様に 31番第4句で `よしの里に`、
   39番第2句で `をの篠原` が含まれない。
8. `npm run test:node` / `npm run typecheck` / `npm run check:eol` が緑。
9. **`packages/**` と `tools/build-data/**` に差分が無いこと**（`git diff --stat` を報告に貼る）。
10. **件数を報告すること**——割れない句・一意に決まった句・表で解いた句の内訳。
    親担当が §3 の予測と突き合わせる。

**受入条件 7 が本体である。** 1〜6 は形が合っているかを見ているだけで、
**「誤った読みで割り付けた」は 2 も 3 も通ってしまう**（`吉野=よし` と割っても、
つなぎ直せば読みは復元する）。**誤形を名指しで拒むことだけが、それを捕まえる。**
