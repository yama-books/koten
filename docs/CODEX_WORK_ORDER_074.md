## 1. 工程1：設定が消える（**不具合。最優先**）

### 1.1 何が起きているか（**原因は特定済み。調査し直さなくてよい**）

**設定の真実が2か所にあり、出題画面が古いほうを保存領域へ書き戻している。**

| 場所 | 中身 |
|---|---|
| `packages/hyakunin/src/main.tsx` の `useState(defaults)`（50行目） | **保存領域から一度も読み込まない。** `noticeConfirmed: false`・学年なしのまま |
| `Home.tsx` の `settings` | `loadSettings()` で読み込む。こちらが正しい |

`Session.tsx` の `persistSettings`（413行目）は `onSettings(next)` と **`port.saveSettings(next)`** を呼ぶ。
`next` は **`main.tsx` の古い設定**から作られる。

**したがって、出題中に「読みを確認する」または「横書きにする」を1度押すと、
`noticeConfirmed` が `false` に戻り、`grade` が消える。**

**結果**：
- ホームへ戻ると「はじめに」がまた出る（**依頼者の報告そのもの**）。
- **学年が失われる。** 統計の学年区分が空になる。**発注073 で必須にした意味が消える。**

**073 で入った不具合ではない。** `main.tsx` の作りは以前からで、
**073 で学年が必須になったことで被害が大きくなり、表面化した。**

### 1.2 裁定

- **設定の真実を1か所にする。** 保存領域を唯一の出所とし、
  **`main.tsx` が `defaults` を持ったまま画面へ配る形をやめる。**
- **どう1か所にするかは実装者が決めてよい**（`main.tsx` で読み込む／`Home` から受け取る／
  読み書きを1つの層へ寄せる等）。**ただし次を必ず満たすこと。**
  - **保存領域に無い項目を、既定値で上書きしないこと。**
  - **画面のどこから設定を書いても、他の項目が消えないこと。**
- **`UserSettings` の項目を増やさないこと。** これは配線の不具合であって、保存形式の問題ではない。
- **既存の設定操作（読み表示・縦横書き・順序）の挙動を変えないこと。**

### 1.3 受入条件（工程1）

- **「はじめに」で学年を選んで OK を押したあと、出題画面で「読みを確認する」を押し、
  ホームへ戻っても「はじめに」が出ないこと。** **この順序どおりに試験を書くこと。**
  **「保存した直後に残っている」だけを見ない**——それは今も通る。
- **同じ経路で `grade` が保存領域に残っていること。**
  **`noticeConfirmed` だけを見ない。** 学年が消えるのが実害である。
- **「横書きにする」でも同じこと**（読み表示だけを直して満足しない）。
- **設定を書く経路が複数あることを、試験が示すこと**——
  **Home から書いても Session から書いても、他の項目が消えない**ことを両方向で見る。
- 既存の設定の釘（読み表示・縦横書き・順序の保存）が**全部緑のまま**残ること。

## 10.9 工程13：結果画面の説明が、何が起きるかを言っていない

**発注069 工程6 で帰属は直った**（説明がそれぞれのボタンの下に付いた）。**残るのは中身である**（㊴）。

いまの文言は「**まちがえた箇所を確認します。**」で、**別の空欄が出るのか、同じ空欄が出るのかが分からない。**
実装は `onRetryWeak(result.retryQuestionIds)` で、**まちがえた問題そのもの（同じ空欄）を出し直す。**

### 10.9.1 裁定

- **「まちがえた歌だけをもう一度」の説明を、依頼者の言い方に沿って書き直す**——
  **「間違えた歌（同じ空欄）で、◯問くりかえし練習します。」に相当する形。**
  **細かい言い回しは実装者が整えてよいが、次の2つは必ず入れること。**
  - **同じ空欄が出ること**（別の空欄ではない）。
  - **何問出るか。**
- **◯問は `result.retryQuestionIds.length` から取ること。数字を文言に直接書かない。**
  **書くと、まちがえた数が変わっても文言だけ古くなる。**
- **「同じ範囲をもう一度」の説明はいまのままでよい**（「同じ範囲でもう一度出題します。」）。

**各回について、次の3つを報告に書くこと。**

6. 本番の問数の一言を消す → その試験だけが赤。
7. 歌番号を2か所に戻す → その試験だけが赤。
