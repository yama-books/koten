## 2. 裁定（この発注の仕様）

### R1：直前の回で間違えた問題だけを再確認する

- 対象は直前の回の `partial / needs-review / incorrect` の問題ID。`correct`・閲覧・未出題問題を入れない。元の出題順を保ち、同じIDは1回にする。同一IDの回答が複数ある場合は最後の判定を採る。
- 穴埋めの位置を変えない。1問だけ間違えたら1問で終わる。同じ歌で2問間違えたら2問。再確認後の再確認は、その再確認の回で残った問題だけを使う。
- 元のモードが本番・紙でも、再確認は画面入力・即時答え合わせ。見出しは「もう一度確認する」。ボタン文言「まちがえた歌だけをもう一度」は維持し、直下に「まちがえた箇所を確認します。」を添える。
- 対象0件ならボタンを出さず、空のSessionを作らない。「同じ範囲をもう一度」は既存の意味を保つ。
- 元の選択範囲は維持し、問題数は実際の再出題数。新しいsessionIdを使い、既存の加点・減点・同一回反復規則は変更しない。
- 再確認専用の出題列を直接Sessionへ渡す。汎用reviewの全問題列を単に `blank` で絞るだけの修正では受け入れない。`planQuestions` 全体の規則変更は不要。
- Session→結果へ `questionId` を明示的に運ぶ。イベントのoutcomeからpartialを逆算しない。現行イベントはpartialもcorrectへ変換するため復元できない。

### R2：再確認の中断と異常時の出口

- 今回作る厳密な再確認列は画面内に保持する。途中の再確認sessionを復元対象として保存せず、完了時だけ既存形式で完了を保存する。回答イベントは既存どおり1問ずつ保存する。
- 再確認画面に「途中で終了すると、この再確認の続きは再開できません。答え合わせ済みの記録は残ります。」を表示する。中断ダイアログもこの意味に合わせる。元の学習・本番の保存規則は維持する。
- 理由：既存Session保存形式には厳密な問題ID列がなく、保存すると再開時に範囲全体へ広がる。今回は保存形式の拡張より、限定した再確認と記録保持を優先する。既存の未完了review記録も穴埋め画面への作者流入を防ぐが、正確な過去の再確認列を推測して復元しない。
- 不正な問題ID・作者問題・空欄を作れない問題を検出した場合は「この問題は表示できません。ホームに戻ってやり直してください。」とホームへのボタンを出す。無回答を誤答として記録せず、問題を黙って落として全問完了にも数えない。
- 最終回答→答えの確認→「次へ」→完了→「結果を見る」まで通す。⑤の操作不能がこの修正後も再現する場合は、その遷移を別の失敗試験として修正する。

### R3：解答後は入力を保持し、要確認は1回

- 練習・再確認の答え合わせ後、送信した入力を同じ入力欄に残し `readOnly` にする。正答への置換、文字の削除・正規化表示はしない。保存失敗時の再試行を壊さない。
- 不正解は「✓ 要確認！」1回。入力欄全体に既存の注意色を付ける。partialは注意色＋「△仮名遣い確認」。色だけで正誤を伝えない。
- 文字ごとの誤り推定・1〜2文字だけの差分強調・新しい編集部品は今回見送る。readonlyの通常inputを使う。
- 本番は採点一覧まで正答・色・判定を出さない。一覧の「自分の答え」も原入力を維持する。紙では架空の入力欄を作らない。

### R4：仮名遣い確認の表記

- 利用者向けの「部分正解」を「△仮名遣い確認」に変更する（練習・再確認の開示、結果内訳、本番採点）。内部の `partial`、判定基準、習熟度の扱いは維持する。
- 補足の完成例は、1行目「歴史的仮名遣い：しろたへの」、次行「（白妙の）」。括弧の中身は `question.answer` そのもの。「原文」「漢字：」というラベルは出さない。
- 漢字の有無は歌全体・入力・読みではなく `question.answer` で判定する。Unicodeの漢字（Script=Han）を1字でも含む場合だけ括弧行を表示する。仮名のみの原文行は省く。正本の内容は変更しない。
- 本番の画面採点もpartial行に同じ2行（漢字なしなら1行）を出す。既存の行ごとの○・△・×のaccessible labelは維持し、△の隣に「仮名遣い確認」を出すことで056 F-4と両立させる。
- 紙の採点は○・△・×のボタンとlabelを維持し、一覧に1回「△は現代仮名遣いで書けた場合です。」を添える。△選択時に該当行の上記補足を出す。
- D-26の「漢字の表記を必ず返す」、D-29の「記号なし」、D-41の表示名は本件の範囲で更新する。内部の5区分は維持。

### R5：変化表の％は小数第1位まで

- 「習熟度の変化」の前・後だけ、小数第1位に四捨五入し不要な `.0` を省く。例：18.400000000000002→18.4%、20→20%、0.8→0.8%。
- 計算値・保存値・集計値は丸めない。メーター等の既存整数表示は維持する（D-57と整合）。会話中の「他画面にも適用」は、長い小数の調査を意味し、全画面の精度変更を意味しない。
