## 3. 手順（**この 5 手だけ。増やさない**）

各行について、次を順に行う。

1. **控えを取る**——`cp <対象ファイル> <控え>`。**Python で書き戻さない**（改行が化ける）。
2. **壊す**——発注054 §6 に書かれた壊し方をそのまま当てる。
3. **当たったことを確かめる**——`grep -c` で置換が **0 件でない**ことを見る。
   **これを省いてはならない。** **「壊したのに全部緑」の原因の 1 位は、破壊が適用されていないことである。**
4. **測る**——`npm run test:screen` と `npm run test:node` を走らせ、**赤くなった試験名を控える。**
5. **戻す**——`cp <控え> <対象ファイル>`。**1 行ずつ戻す。複数の破壊を重ねない。**

**時間の上限を必ず付けること。** **破壊が「赤くならず、終わらない」ことがある**——
棄却サンプリングや繰り返しを壊すと無限ループになる。**1 回の実行が 5 分を超えたら中断し、その旨を報告する。**
