## 6. つまずきやすい点

設計中に実際に間違えた、または間違えかけた箇所。

**発音と表記は別の段である。** 参照した教科書は答えを「コーシ」「チョーズ」とカタカナ長音で示すが、同じページの演習は「現代仮名遣いで答えよ」と要求する。**ツールの正解は `こうし`・`ちょうず` であって `コーシ` ではない。** 完全一致採点なので、ここを混同したデータが1件でも入ると誤採点になる。長音符「ー」を正規化せず誤りとして扱うのは意図的である（設計書 §5.1）。

**`L4`（オ段＋う）は恒等変換である。** 教科書のルール⑤ⓓは発音の規則であり、表記は変わらない（`ようい→ようい`）。一次資料として記録するが出題しない。

**`L1-a` は規則ではない。** 内閣告示第2の「オ列の仮名に『お』を添えて書く」語群（`こおり`・`とお`・`おおかみ`・`ほのお`）は、すべて `H1` と `W2` だけで正しく導出できる。告示がこれを特例としているのは、告示が現代語の音から出発しているためである。独立規則として立てると偽の規則が混入する。

**`H1` には語頭・複合語以外の例外がある。** `はは`（母）は歴史的・現代とも `はは` だが、`H1` を機械適用すると `はわ` になる。一方 `ほほ`（頬）は `ほお` になる。語彙的例外であり、P1c で網羅的に洗い出す必要がある。

**仮名だけでは語が定まらない場合がある。** `くわし` は 菓子（`K1` で `かし`）とも 詳し（歴史的 `くはし`、`H1` で `くわし` のまま）とも読める。`K1` の出題語には制約がある（設計書 §9.3）。

**長音3規則はローマ字でしか正確に書けない。** `せう→しょう` を「エ段＋う は 拗音ょ＋う」と仮名で言い換えると、`せ` が `しょ` になる理由を説明できない。子音が保存され母音だけ変わる規則であり、仮名は子音を単独で表記できないためである（設計書 §3.3）。
