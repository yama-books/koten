## 0. この発注の位置づけ（**先に読むこと**）

## 2. 裁定済み事項（**これに従う。決め直さない**）

### 裁定 1: **実装は正しい。試験だけを直す。**

F-2 の「Enter が飛ばない」性質は **`packages/hyakunin/src/domain/flow.ts:66` の `advance()` が
`state.phase !== 'revealed'` で `state` をそのまま返すことで守られている。**
**画面側の phase 判定は二重の守りである。どちらも消さない。**
試験が発火していなかっただけであり、**実装の欠陥ではない。**

### 裁定 2: **keydown はハンドラのある要素へ投げる。**

`onKeyDown` は `<main>` にある。**`root`（その親）へ投げてもイベントは上へ伝播するので発火しない。**
実測で確認済み（HANDOFF §6・第15回）。**投げ先は必ず `root.querySelector('main')` とすること。**

### 裁定 3: **B-8 の穴は「判定が変わらないこと」を見る試験で塞ぐ。**

読み表示を切り替えた**後に回答**し、**切替前と同じ判定になること**を assert する。
`hintUsed` を見る既存試験（`session: reading toggle records hint use`）とは**別の 1 本**にする。
**1 本にまとめない**——まとめると B-7 と B-8 が同じ 1 本を赤にして、また粒度が失われる。

### 裁定 4: **保存失敗の試験は 2 本に割る。**

現在 `session: saving failure keeps the input and does not reveal` の 1 本に 3 つの assert が同居している。
**`assert` は最初の失敗で止まるため、開示の性質が壊れると入力保持の assert は一度も評価されない。**
計画 §12.3（1 試験 1 目的）に従い、**「答えが出ない」と「入力が残る」を別々の試験にする。**

### 裁定 5: **閲覧画面の試験を新しいファイルに作る。**

`tests/screen/viewer.test.tsx` を新設する。**閲覧画面へ実際に入り、前後移動を観測する。**
現在、閲覧画面へ入る画面試験は**1 本も無い**。
`hyakunin-viewer-navigation.test.ts` は名前に反して**ソース正規表現検査**であり前後移動を見ていない。

### 裁定 6: **`no-pressure` の走査対象へ `.ts` を含める。**

現在 `.tsx` だけを集めているため、`ui/adapters/indexeddb-port.ts` に `setTimeout` を入れても全緑になる（実測）。
**`.ts` と `.tsx` の両方を集めること。**
**`indexedDB` を禁止語に足さないこと**——`adapters/` はそれを使ってよい唯一の場所である（D-35）。
**対象が空でないことと、`Session.tsx` と `indexeddb-port.ts` の両方が対象に入っていることを assert する。**

### 裁定 7: **公開範囲を守る回帰試験を足す。**

`Home.tsx` の読み込み先 URL が**テンプレートリテラルに戻されたら赤くなる**試験を
`no-pressure.test.tsx` に足す。理由は HANDOFF §8 の F-4 である——
`new URL()` の引数が動的だと**バンドラが `data/generated/` を丸ごと公開成果物へ出力する。**
**`new URL(` の引数にバッククォートが現れないことを、`Home.tsx` のソース文字列に対して assert する。**

## 5. 破壊試験（**受入の中心。ここが本題である**）

**実装を 1 箇所だけ反転させ、狙った試験だけが赤くなることを示す。**
**反転させたら必ず元へ戻し、戻した後の `sha256sum` を報告に貼る。**
**`packages/` を反転させたら必ず復元すること。復元は `git checkout` ではなく事前に取った控えから行う**
（`packages/hyakunin/src/ui/` は未追跡ファイルを含むため）。

| # | 反転させる論理 | 赤くなるべき試験 |
|---|---|---|
| **C-1** | `Session.tsx` の `submitAnswer` の入力を、読み表示が `no-ruby` 以外のとき変える | **裁定 3 で足した試験だけ**が赤くなり、`hintUsed` を見る試験は**緑のまま** |
| **C-2** | `Session.tsx` の `persistSettings` から `useHint` の行を消す | **`hintUsed` を見る試験だけ。** 裁定 3 の新試験は**緑のまま**（2 本が別々の性質を固定している証明） |
| **C-3** | `Session.tsx` の保存失敗時に入力を捨てる（`setInput('')`） | **「入力が残る」ほうの 1 本だけ。**「答えが出ない」ほうは**緑のまま** |
| **C-4** | `Session.tsx` で保存を待たずに開示する | **「答えが出ない」ほうの 1 本だけ。**「入力が残る」ほうは**緑のまま** |
| **C-5** | `Home.tsx` の `次の歌` を `selected[index]` にする（動かなくする） | **`viewer.test.tsx` だけ** |
| **C-6** | `ui/adapters/indexeddb-port.ts` に `setTimeout` を 1 件足す | **`no-pressure` だけ**（`.ts` を見るようになった証明） |
| **C-7** | `Home.tsx` の URL をテンプレートリテラルへ戻す | **裁定 7 の回帰試験だけ** |
| **C-8** | `no-pressure.test.tsx` の対象一覧を**空配列**に差し替える | **「対象が空でない」assert が赤くなること**（032 の B-13 と同じ性質を保つ） |

**C-1 と C-2 の「他方が緑のまま」が、B-7 と B-8 の穴が本当に塞がった証明である。**
**C-3 と C-4 の「他方が緑のまま」が、F-1 の粒度が直った証明である。**

**どれかが期待どおりにならなかった場合、「全部緑でした」と報告せず、
どれがどうならなかったかを報告して止まること。**
