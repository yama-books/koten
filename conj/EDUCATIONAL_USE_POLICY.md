# 活用表アプリ 学校授業利用・再利用判定方針

更新: 2026-09-19

## 1. 目的

本アプリは学校の学習目的で使用する。
ただし、GitHub Pages等の一般公開と、実際の授業で生徒に限定して利用する場合では適用できる著作権上の根拠が異なるため、公開範囲を二層に分けて管理する。

この文書は法的助言ではなく、教材実装上の保守的な運用基準である。

---

## 2. 配信モード

### A. PUBLIC モード

不特定多数がアクセスできるGitHub Pages等。

利用可能:
- パブリックドメイン
- CC BY / CC BY-SA等、条件を満たして再利用できる公開本文
- 提供元が明示的に再配布・教材利用を許可している本文
- その他、個別に許諾を得た本文

原則として利用しない:
- 著作権法35条だけを根拠とする本文
- 中納言 / CHJから取得した原文・前後文脈
- 利用条件が不明なWeb本文
- 検索結果に見えるだけで再利用条件を確認できない本文

PUBLICモードでは従来の4ゲートを維持する。

作品 × provider × edition:
1. sourceFound
2. rightsVerified
3. editionFixed

用例:
4. targetVerified
5. excerptReviewed

---

### B. CLASSROOM モード

学校の授業の過程で、教員と当該授業を受ける生徒に限定して使う非公開モード。

著作権法35条の授業利用を利用根拠にできる可能性がある。

CLASSROOMモードで35条依拠を認める条件:

1. 学校その他の非営利教育機関における利用
2. 教育を担任する者又は授業を受ける者による利用
3. 実際の「授業の過程」に供すること
4. 授業上必要と認められる限度
5. クラス・授業単位の限定された利用
6. 著作権者の利益を不当に害しないこと
7. インターネット等を用いる公衆送信では、学校設置者側の授業目的公衆送信補償金制度の適用関係を確認すること
8. 出典・作品名・版を可能な限り表示すること
9. 市販教材・ドリル等の購入代替となるような複製はしないこと
10. 必要最小限の短い文脈に限定すること

CLASSROOMモードであっても、アクセス制御なしの一般公開Webには載せない。

---

## 3. CHJ / 中納言の扱い

重要: 著作権法35条とCHJの契約上の利用条件は別に扱う。

CHJオンライン版の利用規約では:
- 利用目的は研究目的
- CHJデータの全部又は一部の複製は禁止
- 研究成果・知見の公表は規約範囲内で可能

したがって、本プロジェクトではCLASSROOMモードであっても以下を固定する。

### CHJから直接配信しないもの
- 前文脈
- 後文脈
- 原文文字列
- anchor全文
- CHJからコピーしたまとまった本文

### CHJから利用するもの
- sampleId
- 開始位置
- target / chjTarget
- 形態論情報
- 活用形判定
- 作品・章題等の位置特定情報
- 統計・集計
- CHJを用いて得た研究上の知見

CHJの用例を参照した場合、可能な箇所では sampleId + 開始位置を監査情報として保持する。

生徒向け本文は、原則として別の公開版・許諾版・授業利用可能な原資料から構成する。

## 4. 学校利用を踏まえた再利用判定

各例に次の2つの可否を別々に持たせる。

### publicEligible
一般公開アプリに掲載できるか。

trueの条件:
- PD / 明示ライセンス / 個別許諾等で公開再利用可能
- targetVerified
- excerptReviewed

### classroomEligible
授業内限定アプリで使用できるか。

trueの条件:
- publicEligible = true
  または
- 著作権法35条に基づく授業利用条件を満たす原資料である
- かつ、その提供元の契約・利用規約に独立した禁止がない
- targetVerified
- excerptReviewed
- classroomOnly = true

CHJ raw本文は、契約上の制約を優先し classroomEligible の根拠には直接使わない。

---

## 5. 実装上のデータモデル

公開本文レコードでは従来:
- exampleEnabledPublic

を維持する。

将来、授業内限定レコードを追加する場合:
- publicEligible
- classroomEligible
- classroomOnly
- legalBasis
  - public-domain
  - open-license
  - permission
  - article35
- accessScope
  - public
  - class
- sourceTermsChecked
- compensationSchemeChecked（公衆送信時）

を追加する。

CLASSROOM用データはPUBLIC配信用JSONと分離する。
GitHub Pages公開ディレクトリへ混在させない。

---

## 6. 中納言表記との関係

文法判定については従来どおり:
- chjTargetを校正済みの基準形として優先
- publicTargetは公開版の実表記
- 根拠不明の文法形差ではCHJを優先
- 妥当な版差・底本差がある場合のみ注記付きで例外

学校利用だからといって、この本文照合基準を緩めない。

---

## 7. 本プロジェクトでの実際の判断

Phase Dの現在の公開本文監査は、**PUBLICモード用データの構築**として続行する。

したがって、
- PD / CC等が確認できる例 → PUBLICへ接続
- 権利はあるが検索可能本文がない例 → PUBLICではblocked
- 35条なら授業利用できそうな例 → PUBLICには昇格させず、将来のCLASSROOM候補として記録可能
- CHJ raw本文 → PUBLICにもCLASSROOMにも直接複製しない

このためPhase Dの厳格さは維持しつつ、blocked例を「授業でも使えない」とは解釈しない。
