## 監査方式改善: 典拠不明の異同では中納言表記を優先

ユーザー補足を反映。

CHJ / 中納言は校正済みコーパス本文なので、公開本文との異同に明確な版・底本・校訂上の根拠がない場合は中納言側を優先する。

今後:
- 文法分類の正本 = chjTarget
- 公開本文の実表記 = publicTarget
- 字種・濁点・踊り字等の表記差は許容
- 活用形や統語形が変わる差は、根拠がない限り公開接続しない
- 妥当な版差・底本差がある場合のみ注記付きで例外扱い
- 同語形の別箇所へのすり替えは禁止

この規則はD-13枕草子で実際に発生した「心ことなり / 心ことなるなり」のようなケースにも適用する。

## 学校利用を踏まえた再利用判定の二層化

学校での学習目的利用を前提として、再利用可否をPUBLICとCLASSROOMに分離した。

### PUBLIC
- 不特定多数への一般公開
- PD / CC等の明示ライセンス / 個別許諾を基本
- 著作権法35条だけを根拠に一般公開しない

### CLASSROOM
- 当該授業の教員・生徒に限定
- 必要性・範囲・権利者利益を考慮し、35条適用を検討可能
- 公衆送信時は設置者の授業目的公衆送信補償金制度の適用関係を確認
- PUBLICとは別JSON / 別アクセス範囲にする

CHJ:
- 中納言利用規約は別に遵守
- raw本文・前後文脈・anchor全文を授業アプリへ直接複製しない
- sampleId / start / target / 形態論情報 / 研究知見を基準情報として使う

新規正本:
- `EDUCATIONAL_USE_POLICY.md`

これによりPhase Dのblockedは「PUBLICでは未接続」を意味し、CLASSROOM利用可能性まで否定しない。
